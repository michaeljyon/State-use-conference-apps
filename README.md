# State Use Conference App Template

React + Vite PWA for State Use conferences: agenda, speakers, venue map, sponsors, materials, notifications, surveys, the Connections Challenge with a live leaderboard, photo gallery and prize drawing. Built on the structure of WVARF's *Statewide Synergy* app.

- **Ships with a sample event.** Everything in `event/event.js` is placeholder content until you replace it.
- **19 brand presets**, one per State Use program, using only each program's official logo and colors (`src/brands/brands.js`).
- **Netlify-ready.** Live features run on a Netlify Function with Netlify Blobs. No database.

```bash
npm install
npm run dev          # http://localhost:5173  (staff passcode: demo)
npm run seed-sample  # optional demo activity, in a second terminal
```

Full instructions: **[SETUP.md](SETUP.md)**.
